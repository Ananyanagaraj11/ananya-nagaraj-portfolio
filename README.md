Personal portfolio showcasing AI/ML engineering projects, technical skills, and professional experience.

## 🌐 Live Demo

**[View Portfolio →](https://ananya-nagaraj-portfolio-3fje.vercel.app/)**

## ✨ Features

- 🎨 Modern responsive design with purple/pink gradient theme
- 🚀 Preloader, then smooth animations (Framer Motion, AOS)
- 📱 Mobile-first layout
- 🌓 Dark mode friendly
- ⚡ Vite + React 18 + TypeScript
- 🎯 Sections: Hero, About, Experience, Projects, Skills, Certifications, Education, Contact

## 🛠️ Built With

| Area | Tech |
|------|------|
| **Core** | React 18, TypeScript, Vite |
| **Styling** | Tailwind CSS, tailwindcss-animate |
| **UI** | Radix UI, shadcn-style components, Lucide React |
| **Motion** | Framer Motion, AOS, React Type Animation |
| **Data** | TanStack React Query |
| **Routing** | React Router DOM |
| **Charts** | Recharts |
| **Deploy** | Vercel |

## 🚀 Quick Start

### Prerequisites

- Node.js 18+
- npm or yarn

### Install & Run

```bash
git clone https://github.com/Ananyanagaraj11/ananya-nagaraj-portfolio.git
cd ananya-nagaraj-portfolio

npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173).

### Build

```bash
npm run build
npm run preview
```
